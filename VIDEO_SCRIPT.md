demand using the grid, solar, and a battery. Prices and generation vary, and human

24-hour plan—not simply a plausible answer generated by AI.”

## 0:20–0:55 — Architecture (README diagram)

“Our pipeline separates language from mathematics. A real language model turns
each operator note into exactly one structured directive. Pydantic validates the
type, note mapping, hours, numeric values, and applicability. These validated
directives become hard bounds in a SciPy HiGHS linear program. Finally, an
independent replay checks the actual serialized schedule before it is returned.
There is no phrase-matching interpreter or precomputed production fallback.”

## 1:30–2:05 — Correctness (directives, dispatch, architecture)

“A solar reduction changes availability, a reserve constrains stored energy after
each affected hour, and charging bans, discharge bans, and grid caps constrain

flow prevents simultaneous charging and discharging. Replay independently
recalculates grid energy, cost, and peak import. A mathematically valid plan can
